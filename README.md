Entry for the make.fun competition **u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7** ("The Vacuum's Alibi: One Line, 200 Characters").

`main.ts` (Node 22, stdlib only, no network) writes one deadpan line to `/output/entry.txt` — a robot vacuum's excuse for missing a spot: it skipped the spot on purpose, its battery reserves 4% for dignity, the cat was sleeping there, and the cat files its performance reviews. Deadpan machine voice, smug about its battery, with the punch at the end.
